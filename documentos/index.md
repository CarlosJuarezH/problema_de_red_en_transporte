# Proyecto de Red Tronco-Alimentadora
Este proyecto modela una red de transporte urbano bajo un esquema tronco–alimentador, tomando como base una red ya existente.  
El objetivo es **optimizar los tiempos de transferencia y mejorar la eficiencia del sistema de transporte público en la ciudad**.

---

## Objetivos
- Validar y organizar los datos de entrada (`input.txt`).
- Diseñar la estructura tronco-alimentadora sobre la red base.
- Implementar un modelo reproducible y abierto para fines académicos.
- Facilitar la reutilización del proyecto en diferentes conextos.
