# Proyecto de Rediseño de Red Tronco-Alimentadora
## Descripción
Este repositorio contiene el material del proyecto de investigación sobre el rediseño de la red de transporte de una ciudad xxxxx.
El objetivo principal es optimizar la integración entre rutas troncales y alimentadoras.

##Estructura del repositorio:
-codigo/: Scripts de modelado y simulación.
-documentos/: Reportes técnicos y artículos en LaTex.
-datos/: Dataset de rutas de transporte urbano.

##Buenas prácticas
-Mantener los datos originales en 'datos/' sin modificarlos directamente.
-Usar mensajes de commit claros y atómicos para reflejar el progreso.
